# Continuous 2D rig prototype

One original Puchu/Pihu soup-apology scene, staged by hand for visual review. Original 2D characters and room share the same outline and palette. Arms use two-link inverse kinematics, legs animate continuously, facial elements respond to emotion and audio, camera cuts follow speakers, and the bowl is handed between actors. Four Hindi character dialogue lines; no narrator. 1280x720, 24fps, measured duration 21.375s. The prototype passed its render/audio checks in run 36841148890.

This is a basic motion and style prototype. It does not reproduce a professional TV studio animation pipeline, and mouth motion is based on audio energy rather than phoneme alignment. The scene staging and camera cuts are authored in scene.py; new stories are not automatically animated from Make yet. The rejected Primary Make daily scenario 7709916 stays paused while the user reviews this direction. No social publishing.
